## 一、项目整体定位

本项目以"肠道花园"为核心创意隐喻，面向家长与儿童双受众，将专业的肠道微生态科学知识转化为可看、可玩、可交互的科普体验。以 AI 技术为驱动，提供知识科普、健康习惯追踪、智能问答三位一体的教育工具。

### 1.1 品牌定义

| 维度 | 详细内容 |
|------|----------|
| 品牌名称 | 肠道花园（Gut Garden） |
| 品牌Slogan | 每一口食物，都在浇灌你的微观生态 |
| 核心隐喻 | 肠道 = 一座生机勃勃的花园，微生物 = 花园里的居民，食物 = 浇灌花园的养分 |
| 视觉风格 | 温暖治愈、手绘童话风；主色调：森林绿（#4E6A3E）+ 奶油米（#FFF9EF）+ 珊瑚粉（#F38D83） |
| 内容调性 | 科学准确 + 轻松亲切；不说教、不恐吓、不伪科学 |
| 技术标签 | 国产开源大模型驱动 AI 科普导览 |

### 1.2 核心差异化

- 以"生态"而非"器官"的视角讲肠道健康，摆脱传统的消化系统解剖学叙事
- "便便小观察"功能填补市场空白 —— 目前没有面向幼龄儿童的便便记录+科普反馈工具
- AI 导览助手将复杂科学"翻译"为儿童可理解的语言
- 科学内容均标注依据，拒绝"排毒""宿便"等伪科学概念

## 二、核心叙事主线

整个网页围绕一个统一的叙事线索展开，用户从一个问题出发，逐步探索整个花园：

### 2.1 叙事逻辑链

- **问题引入**: 你知道吗？你的肠道里住着万亿个微小居民。它们组成了一座花园。
- **花园认知**: 这座花园需要什么养分？膳食纤维是它们的食物。不同的食物喂养不同的居民。
- **花园运转**: 居民们发酵纤维，产生短链脂肪酸——这些'魔法养分'滋养你的肠道屏障，影响你的全身健康。
- **花园变化**: 饮食单一、熬夜压力、滥用抗生素——都会让花园'天气'变差。但好消息是：你每天都可以修复它。
- **花园观察**: 怎么知道花园好不好？便便就是花园寄来的'天气报告'。每日简单记录，就能读懂它的信号。
- **花园行动**: 每天多喝一杯水、多吃一种蔬菜、早睡半小时——浇灌你的肠道花园。

### 2.2 叙事的优势

- 与"肠道花园"视频脚本完全一致，多媒体内容可互相引用
- 生态隐喻天然具备延展性（天气、季节、居民、养分…）
- 便便观察自然地嵌入叙事，不会显得突兀
- 故事弧线完整：好奇 → 认知 → 行动 → 反馈

## 三、目标受众分析

| 维度 | 家长（决策者/买单者） | 儿童（使用者） |
|------|----------------------|----------------|
| 年龄 | 25-40 岁 | 3-10 岁 |
| 核心需求 | 孩子的肠道健康管理、饮食习惯培养、便便是否正常的判断 | 好玩、有互动、被奖励、能听懂 |
| 使用场景 | 每日饭后/睡前 5 分钟，陪孩子一起使用 | 家长陪同或自主探索 |
| 关注点 | 科学依据是否可靠、操作是否简单、是否真正有帮助 | 画面可爱吗、有没有故事、能不能得到星星 |
| 阅读能力 | 可理解专业内容（SCFA、菌群等） | 大字+图片为主，文字简短有韵律 |
| 互动方式 | 设置提醒、查看报告、咨询 AI | 点按、拖拽、选择表情、收集徽章 |

### 设计原则

同一个页面提供 **"家长深度模式"和"儿童简易模式"两种阅读层级**。关键数据看板和科学注释默认折叠，对儿童展示的为主视觉 + 简短文案 + 大按钮。

## 四、页面架构总览

全站采用"花园主题"单页应用（SPA）结构，主导航 5 项 + 底部常驻打卡入口。

### 4.1 导航栏

| 导航项 | 图标 | 说明 | 优先级 |
|--------|------|------|--------|
| 花园首页 | 花朵 | 全景导览 + 花园状态看板 + 快捷入口 | P0 |
| 探索课堂 | 放大镜 | 5大知识模块 + 科普视频 + 互动问答 | P0 |
| 便便小观察 | 便便 | 便便记录 + 饮食打卡 + AI 反馈 | P0 |
| 健康问问 | AI 头像 | 智能问答 + 常见问题推荐 | P1 |
| 成长星图 | 星星 | 徽章墙 + 成就记录 + 历史趋势 | P1 |

> 导航不超过 5 项，避免认知负担。每日打卡入口在底部常驻浮动按钮，不在主导航中独占一项。

### 4.2 页面整体布局

**顶部区域（每个页面共享）**:
- 品牌栏：肠道花园 logo + 花园当前状态表情（😊/😐/😢 基于打卡数据变化）
- 导航标签：5 个导航项
- 用户打卡进度条：今日喝水/蔬菜完成度（收缩后可展开）

**底部区域（每个页面共享）**:
- 浮动打卡按钮：圆形按钮，"今日浇水了吗？"
- 页脚：科学依据声明 + 免责声明 + 项目介绍

### 4.3 用户流

1. 用户打开网页 → 花园首页（花园全景 + 状态看板）
2. 新用户 → 引导提示（"欢迎来到肠道花园！"）+ 快速四步引导
3. 老用户 → 直接看到今日花园状态 + 待办打卡项
4. 点击导航进入各板块
5. 完成任务/打卡 → 获得经验值 → 徽章解锁

## 五、板块详细内容规划

### 5.1 首页 · 花园全景

**目标**: 让用户在 3 秒内理解"肠道花园"是什么，并快速进入核心功能。

| 区块 | 内容 | 交互方式 |
|------|------|----------|
| 主视觉区（Hero） | 花园全景插画 + "你的肠道里，藏着一座花园" / 副标题："每天三件小事，浇灌你的微生态" | 背景随花园状态变化色调；"开始探索"按钮 → 引导流程 |
| 花园状态看板 | ① 今日纤维摄入（绿色进度条）② 今日水分补充（蓝色进度条）③ 昨晚睡眠质量（月亮表情） | 点击卡片展开详细记录；数据来自每日打卡模块 |
| 花园今日天气 | ☀️"今天花园阳光灿烂！"/ ⛅"花园需要更多蔬菜哦" / 🌧️"花园有点干燥，多喝水吧" | 动态文本每日更新；可分享为卡片图片 |
| 快捷入口 | 4个入口卡片：探索课堂 / 记录便便 / 问问AI / 我的星图 | 点击跳转对应板块 |
| 今日推荐 | 一条精选知识点 + 一条可行动建议 | 每日更换；点击"去看看"跳转探索课堂 |

### 5.2 探索课堂 · 知识模块

网页的核心科普内容区。基于已有的 20 条知识卡片，整合为结构化的"花园知识体系"。

**页面布局**:
- 顶部：花园地图式导航，5 个知识模块以"花园区域"的形式呈现
- 每个区域可展开/折叠，点击进入知识卡片列表
- 右上角：知识检索 + "随机探索"按钮

#### 五大知识模块

| 模块名称 | 花园隐喻 | 核心知识点（3-4条/模块） | 素材状态 |
|----------|----------|--------------------------|----------|
| ① 膳食纤维广场 | 花园的"土壤养分" | 什么是膳食纤维？/ 哪些食物富含膳食纤维？/ 为什么食物多样性重要？/ 增加纤维应循序渐进 | ✅ PSD完成 |
| ② 发酵工坊 | 花园居民的"厨房" | 什么是肠道微生物群？/ 好菌坏菌不是简单的二分法 / 饮食如何影响微生态 / 每个人的菌群都独一无二 | ✅ PSD完成 |
| ③ 短链脂肪酸泉 | 花园的"能量泉水" | 什么是短链脂肪酸？/ 乙酸、丙酸、丁酸各有什么作用 / 纤维→发酵→SCFA链条 / 丁酸是结肠细胞的燃料 | ✅ PSD完成 |

| ⑤ 生态平衡观测站 | 花园的"气象站" | 睡眠不足如何影响肠道 / 运动与压力管理 / 抗生素的双刃剑效应 / 出现持续症状应及时就医 | ⚠️ 需扩充 |

#### 每张知识卡片的交互设计

- **卡片正面**: 可爱插画 + 知识点标题 + 一句话摘要
- **卡片翻转/展开**: 详细科学解释（家长模式）+ 儿童语言版 + "科学依据"标签（点击展开参考文献）
- **底部按钮**: "加入今日打卡"（转化为行动）+ "问问AI"（打开问答助手）

#### 互动问答选择题

每个模块尾部配置 2-3 道选择题，强化学习效果：

| 题目类型 | 示例 | 交互方式 |
|----------|------|----------|
| 知识巩固 | "下列哪种食物富含膳食纤维？A.白米饭 B.燕麦 C.肥肉 D.奶酪" | 选择后给对错反馈 + 解释 |
| 生活场景 | "小明今天只吃了白米饭和红烧肉，他的肠道花园会？A.很开心 B.缺营养 C.没影响" | 用花园角色语气回答 |
| 行为引导 | "下面哪个习惯对肠道花园最友好？A.熬夜到12点 B.每天喝足水 C.不吃蔬菜" | 强化正向行为 |

#### 科普视频

在探索课堂顶部放置 90 秒"肠道花园"科普动画（视频脚本已就绪），视频下方引导至便便观察/打卡。

### 5.3 便便小观察 · 智能记录

**这是整个项目的核心差异化功能**。目前市场上没有专门面向幼龄儿童、以"便便 + 饮食"关联分析为特色的科普教育工具。

#### 便便观察主界面

| 功能区域 | 详细内容 | 交互说明 |
|----------|----------|----------|
| 便便记录区（核心） | 5种简化Bristol便便分类图标：①硬颗粒（兔子便便）→缺水 ②香蕉状光滑条状→理想✅ ③表面有裂缝条状→基本正常 ④糊状/软便→纤维不足 ⑤水状/腹泻→需关注 | 儿童选择便便表情；家长可补充文字备注；每日可选多次 |
| 同时打卡 | ☐ 今天喝了足够的水 / ☐ 今天吃了蔬菜 / ☐ 今天吃了水果 / ☐ 今天户外活动了 | checkbox勾选；完成3项以上额外加分 |
| AI反馈 | "今天便便形状很健康！蔬菜也吃够了，花园在开心地生长 🌱" / "便便有点干哦，明天要多喝水，花园需要灌溉 💧" | 根据便便类型+饮食打卡综合生成个性化反馈 |
| 历史记录 | 最近7天便便记录一览（图标+绿/黄/红健康标注） | 左右滑动切换日期；点击某天查看详情 |

> **隐私声明**: 所有数据仅存储在用户本地浏览器，不上传服务器。便便不拍照不上传，仅选择图标。

#### 便便与饮食的关联分析

数据积累 3 天后，AI 给出关联趋势：
- "这周有 3 天蔬菜吃得少，那几天的便便偏硬哦"
- "喝水充足的日子，便便形状更理想！"
- "昨晚睡得晚，今天便便状态没那么好"

#### 安全边界设计

- 标注"本工具用于健康科普与习惯养成，不能替代医生诊断"
- 连续 3 天水样便或持续便秘 → 建议就医提示
- 不存储任何个人身份信息（不需要注册登录）
- 不提供医疗建议，只做科普反馈
- 便便数据图表仅展示趋势，不下诊断结论

### 5.4 健康问问 · AI 问答

基于国产开源大模型的 AI 问答助手，以"肠道花园导游"的角色，用亲切易懂的方式回答肠道健康相关问题。

#### 页面布局

| 区域 | 内容 |
|------|------|
| AI 角色展示 | 花园角色（菌小园或丁丁泉灵）+ "你好，我是你的肠道花园导游！" |
| 输入框 | "输入你的问题…" + 发送按钮 |
| 快捷问题推荐 | 6-8 个常见问题气泡（为什么要慢慢吃饭？/ 肠道里的好菌喜欢什么？/ 酸奶对肠道有好处吗？/ 为什么吃多了会肚子疼？/ 一天要喝多少水？/ 益生菌是什么？/ 吃辣椒会伤胃吗？/ 为什么放屁会臭？） |
| 回答展示 | AI 回答（儿童友好版 + 可点击"看科学依据"展开参考资料） |

#### AI 回答风格指南

1. 用花园隐喻开头（"这个问题就像花园里的……"）
2. 先给简短结论（一句话），再给详细解释
3. 避免绝对化表述（"一定""绝对不要"）
4. 复杂概念用类比（"紧密连接就像花园栅栏的扣锁"）
5. 结尾加一个可操作建议
6. 所有科学声明标注可信来源
7. 超出范围的问题回复"这个问题需要咨询医生哦"

## 六、便便小观察功能详设

### 6.1 功能流程

1. **Step 1: 选择便便类型** — 展示5个卡通便便图标，选中的放大+确认按钮
2. **Step 2: 补充打卡** — 展示今日打卡checkbox列表（水、蔬菜、水果、运动），UI提示引导
3. **Step 3: AI 反馈** — 根据便便类型+饮食打卡生成1-2句花园状态反馈，语气亲切不评判
4. **Step 4: 记录完成** — 显示今日摘要+明日提醒，返回首页花园状态更新

### 6.2 Bristol 便便分类简化版（面向儿童）

| 类型 | 童趣名称 | 形状描述 | 可能含义 | 花园状态 |
|------|----------|----------|----------|----------|
| Type 1 | 兔子便便 🐰 | 一颗颗硬硬的小球 | 可能喝水不够 | 🌧️ 干旱了 |
| Type 2 | 葡萄串 🍇 | 一团一团的硬块 | 需要更多纤维 | ⛅ 缺营养 |
| Type 3-4 | 香蕉宝宝 🍌 | 光滑的条状（理想型） | 状态很好！ | ☀️ 阳光灿烂 |
| Type 5 | 软冰淇淋 🍨 | 柔软的糊状 | 可能纤维不足 | ⛅ 有点软 |
| Type 6 | 水水 💧 | 水状/腹泻 | 需要关注 | 🌧️ 暴风雨 |

### 6.3 数据隐私策略

- 所有数据存储在用户浏览器 localStorage，无需注册登录
- 不上传任何便便数据到服务器
- AI 问答仅处理当前输入文本，不关联历史便便记录
- 页面底部显著位置展示隐私说明

| 🏃 户外活动 | 至少30分钟活动 | 花园通风 | +10 |
| 🌙 早睡 | 在合理时间入睡 | 花园夜间修复 | +10 |
| 💩 便便记录 | 记录一次便便类型 | 花园天气报告 | +5 |

### 7.2 打卡交互设计

- 底部浮动按钮："今日浇水了吗？"（始终可见）
- 点击弹出打卡面板，展示今日待办项
- 完成一项打勾 + 微动画（水滴落下/绿叶长出）
- 首页顶部进度条实时反映今日完成率
- 每天 0 点重置，但保留昨日完整记录供回顾

### 7.3 正向强化设计

- **不使用"断卡"惩罚逻辑**（连续打卡断了不扣分不降级）
- 强调"今天做了什么都值得鼓励"
- 徽章是正向累积，不设负向惩罚
- AI 反馈语言保持积极性（"明天可以试试多吃一种蔬菜哦"而非"你今天没吃蔬菜"）

## 八、AI 能力规划

**核心定位**: 将复杂的肠道科学"翻译"为儿童和家长可理解的互动体验。

### 8.1 AI 功能清单

| 功能 | 能力描述 | 技术实现方式 | 优先级 |
|------|----------|-------------|--------|
| AI 问答助手 | 回答肠道健康问题，用花园隐喻和儿童友好语言 | 国产大模型 API + 预设回答模板 | P0 |
| 便便反馈生成 | 根据便便类型+饮食打卡，生成个性化花园状态反馈 | 规则引擎 + AI 润色 | P0 |
| 知识卡片内容生成 | 辅助生成新知识卡片的儿童版文案 | AI 文本生成 + 人工审核 | P1 |
| 打卡建议推荐 | 基于历史记录给出明日改善建议 | 简单规则系统 | P1 |
| AI 科学翻译 | 用户输入复杂问题，AI 翻译为儿童能理解的语言 | 大模型 API | P1 |
| 徽章成就贺词 | 解锁徽章时 AI 生成个性化祝贺语 | 模板 + 变量填充 | P2 |

### 8.2 AI 角色设定

- **名称**: 菌小园（取自"菌"和"花园"）
- **人格**: 亲切、好奇、懂科学的"花园小导游"，知道很多肠道知识但从不摆架子
- **语气**: 使用花园相关比喻、语速适中、不打断用户、不确定时会说"这个问题我需要查查资料"

### 8.3 AI 安全边界

- 所有 AI 回答末尾标注"本项目用于科学传播，不构成医疗建议"
- 医疗相关问题（用药、诊断、症状判断）引导至就医
- 敏感内容过滤
- AI 不应回答超出肠道健康科普范围的问题
- 不支持也不暗示任何诊断能力
