# 视觉设计审查报告：肠道花园（Gut Garden）

> **审查日期**: 2026-07-30
> **审查方**: design-mastery:design-master
> **审查对象**: PRD §4.1-§4.6 + 系统设计 §1.5 + §6 美术素材规范
> **当前方案**: 2D 手绘童话风，主色 #4E6A3E / 背景 #FFF9EF / 点缀 #F38D83，CSS 3D 视差 + Lottie 角色

---

## 一、色彩体系

### 1.1 色板分析

| 角色 | 色值 | 功能定位 |
|------|------|----------|
| 森林绿 #4E6A3E | 主色 | 花园植被、头部、按钮 |
| 奶油米 #FFF9EF | 背景色 | 大面积底色 |
| 珊瑚粉 #F38D83 | 点缀色 | 徽章、按钮、强调 |

### 1.2 30% 辅助色缺失

60-30-10 法则要求主色 60%、辅助色 30%、点缀色 10%。#FFF9EF 作为背景不应计入配色比例。实际运行时页面绝大多数面积是奶油色的"空"，缺少一个辅助色来丰富视觉层次。

### 1.3 色盲无障碍

#4E6A3E 与 #F38D83 在红绿色盲视角下对比度严重下降（儿童色盲检出率约 8%）。建议为颜色编码的状态增加纹理/形状第二编码：
- 健康花园 vs 干枯花园 → 叠加龟裂纹理
- 按钮完成 vs 未完成 → 叠加 ✓ 图标

### 1.4 跨年龄段适配

3-5 岁前运算期偏好高饱和度；6-10 岁具体运算期可以接受更复杂的色彩组合。#4E6A3E 饱和度约 35%，对低龄段可适当提升至 50-55%（#5B7A46），或在高龄/知识卡片界面恢复柔和调色板。建议在设置中让家长选择年龄段，据此调整字号与色彩。

## 二、风格一致性

### 2.1 隐喻映射

| 隐喻元素 | 视觉转化 | 评估 |
|----------|----------|------|
| 肠道 → 花园 | 横版花园场景 | 强 |
| 微生物 → 居民 | 8 个拟人角色 | 强 |
| 食物 → 养分 | 浇灌动画 | 中 |
| 消化过程 → 知识卡片 | 5 张独立卡片 | **弱 — 此处断裂** |

### 2.2 知识卡片的产品形态

独立静态卡片无法传达"食物从入口→分解→吸收→排出"的过程感。建议将 5 张卡片改造为**纵向流程站点**——用一条纵向食物旅行路径串联 5 张卡片，每张卡片是路径上的一个站点，站点之间用 CSS 粒子动画（食物颗粒向下移动）串联。不改动已有 PSD 素材，只在布局层面增加连线 + 箭头 + 滚动驱动的进入动画。

### 2.3 手绘风格 × CSS 3D 视差的张力

纯 2D 手绘贴图在 CSS 3D 空间中做透视变换时可能暴露"假 3D"的生硬感。建议：
- 视差层只做位移视差（translateX/Y 不同速度），避免 scale 变换
- 每层插画边缘添加柔和阴影遮盖裁切痕迹
- Lottie 角色只出现在中景层（translateZ: 0）

### 2.4 装饰密度梯度

不同页面类型应采用不同的装饰密度：
- **花园场景页（探索模式）**：80-90% 填充度，沉浸式体验
- **知识卡片页（学习模式）**：≤ 40%，背景保持奶油色，仅卡片带装饰
- **徽章/设置页（系统界面）**：≤ 20%，接近扁平 UI

│  ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─    │

### 3.2 字体层级

| 层级 | 字号 | 行高 | 字体方向 |
|------|------|------|---------|
| 儿童文本 | ≥ 18px | 1.6x | ZCOOL KuaiLe / Comic Neue 等圆体 |
| 家长文本 | 14-15px | 1.4x | 思源宋体 / Noto Serif SC |

### 3.3 家长入口

使用半透明 📖 图标（20×20px）置于角落，避免与儿童主按钮竞争。在家长首屏引导中加入一次提示即可。

### 3.4 年龄段自适应

3-5 岁：纯视觉叙事，文字仅作为家长伴读解说词（可加朗读按钮）
6-10 岁：图文并茂，短句 + 图标辅助

## 四、角色设计

### 4.1 8 角色差异化评估

| 角色 | 原型映射 | 差异化风险 | 改进方向 |
|------|----------|------------|----------|
| 菌小园 | 益生菌向导 | 低 | 可加小放大镜或实验服暗示"科学导游" |
| 纤纤种子 | 膳食纤维 | 中 | 强化线状/网状特征——细长身体，编织纹理 |
| 杂草坏菌 | 有害菌 | 高 | 走"灰暗但圆润"路线：灰绿/暗紫色调，棱角增多但保持可亲（参考《头脑特工队》忧忧） |
| 丁丁泉灵 | 水/水分 | 中 | 增加透明/半透明质感区 |
| 香蕉小船 | 短链脂肪酸 | 低 | 保持 |
| 风车蘑菇 | 肠道绒毛 | 高 | 蘑菇伞设计为绒毛簇状，呼应肠道绒毛形态 |
| 云角马 | 映射不明确 | 极高 | 建议降级为装饰 NPC 或从 MVP 移除 |
| 虎宝 | 免疫/屏障 | 中 | 身体上增加盾牌或城墙元素 |

### 4.2 "粘土/绒布"质感

方向正确但实施有风险。建议统一采用 2D 手绘风格 + 多层渐变 + 投影模拟立体感（假 3D 着色），保持与场景插画风格一致。

### 4.3 剪影测试

每个角色去色后仅看轮廓应有辨识度：菌小园（蘑菇帽+圆眼镜）、纤纤种子（橄榄形+编织纹理）、香蕉小船（弧形+帆）、虎宝（条纹+大圆脸）。

## 五、交互与动效

### 5.1 CSS 3D 视差风险

| 风险 | 等级 | 说明 |
|------|------|------|
| 低端设备性能 | 高 | 4 层视差在集成显卡/旧 iPad 上可能卡顿 |
| 晕动症 | 中 | 3-6 岁儿童前庭系统未发育完全 |
| Safari 兼容 | 中 | preserve-3d 在 iOS Safari 有已知渲染 bug |

建议：缩减至 3 层（天空+远景合并）+ 最大位移 ≤ 视口宽度 5% + 帧率 < 30fps 自动降级为静态背景。

### 5.2 动画规范

- 入场：淡入 + 小幅上移，800-1000ms ease-out
- 翻转：CSS 3D flip，600ms ease-in-out
- 徽章获得：缩放 1→1.15→1（三次呼吸），配合金色粒子
- 按钮悬停：scale 1.05 + box-shadow 增强
- **禁止**：旋转、抖动、频闪（WCAG 2.3.1 癫痫风险）

### 5.3 可交互元素识别

可交互元素增加微呼吸动画（小幅度上下浮动 0.8-1.2s cycle）+ 2px 半透明发光边缘，避免页面看起来像一张静态插画。

## 七、风险与优先级

### P0 — 必须解决

| # | 风险 | 建议 |
|---|------|------|
| 1 | 2D插画视差层 × 粘土Lottie角色风格断裂 | 统一为 2D + 假 3D 着色，角色与场景同风格 |
| 2 | 色彩无障碍：绿+粉在色盲视角下消失 | 增加纹理/形状第二编码，页面截图通过色盲模拟工具验证 |
| 3 | 知识卡片独立形态 vs 消化过程感不匹配 | 改为纵向流程站点串联（见 §2.2） |

### P1 — 强烈建议

| # | 风险 | 建议 |
|---|------|------|
| 4 | 视差性能：4 层在低端设备卡顿 | 缩减 3 层 + 30fps 自动降级 |
| 5 | 杂草坏菌/风车蘑菇/云角马辨识度不足 | 强化轮廓差异化（见 §4.1） |
| 6 | 3-5 岁低龄段色彩吸引力不足 | 低龄界面局部增加高饱和度元素 |

### P2 — 建议优化

| # | 风险 | 建议 |
|---|------|------|
| 7 | 文具化：页面像插画而非交互界面 | 可交互元素加微呼吸动画 + 发光边缘 |
| 8 | 便便图标的文化适应性待验证 | 对 7 个图标做家长问卷 |
