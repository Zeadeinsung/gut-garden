### 0.4 怎么上传到 GitHub（零基础版）

**不需要安装任何软件，用浏览器就能完成。**

前提：我已经把你加为项目协作者，你会收到一封 GitHub 邀请邮件，点 "Accept invitation" 即可。

**第一步：进入项目**
1. 打开浏览器，访问项目地址（我问开发者要）
2. 右上角登录你的 GitHub 账号（没有的话去 `github.com` 注册一个，2 分钟）

**第二步：建文件夹 + 传文件**
1. 在项目页面找到 `web/public/assets/` 目录点进去（如果目录还不存在，告诉开发者先建好）
2. 进入对应子文件夹（如 `scenes/`），点右上角 "Add file" → "Upload files"
3. 把素材文件从电脑拖进浏览器窗口
4. 在 "Commit message" 框里写一句话，比如 `添加场景背景图`
5. 点绿色 "Commit changes" 按钮

**第三步：逐个文件夹重复**
- scenes / characters/png / characters/lottie / cards / foods / stools / badges/icons / badges/frames / ui / lottie/effects / onboarding —— 每个子文件夹都重复第二步
- 一次可以拖多个文件，不用一个一个传

**一句话总结：打开 GitHub 网页 → 点进文件夹 → Add file → Upload files → 拖文件进去 → Commit。**

## 八、徽章图标

### 8.1 徽章视觉规范 — 两层分离架构

徽章采用「**中央图标 + 通用边框**」的两层分离设计，由前端叠加合成：

```
┌─────────────────────┐
│   [边框层: PNG]      │  ← 铜/银/金 3 个通用边框，前端根据稀有度动态叠加
│  ┌───────────────┐  │
│  │  中央图标: PNG  │  │  ← 美工只画 21 个中央图标，透明底，512×512px
│  │               │  │     同一枚徽章升级时图标不变，只换外面那层边框
│  └───────────────┘  │
└─────────────────────┘
```

**优势**: 美工不需要为每枚徽章的每种稀有度单独出图。徽章升级（铜→银→金）只换 CSS class，不需要新素材。

| 层级 | 交付物 | 格式 | 画布 | 说明 |
|------|--------|------|------|------|
| 中央图标 | `badge_{code}_icon.png` | PNG-24，透明底 | 512×512px，72 DPI，≤200KB | 每枚徽章的插画主体 |
| 边框模板 | `ui_badge_frame_bronze.png` 等 | PNG-24，透明底 | 512×512px，72 DPI，≤100KB | 圆形镂空边框，中央透明露出图标 |

## 附录 B：Lottie 制作要点

1. AI/PS 设计角色各部件（身体、四肢、五官、装饰），**分层命名**
2. 导入 AE，对每层做关键帧动画（位移/旋转/缩放/透明度）
3. Bodymovin 插件导出 `.json`，勾选 "Glyphs"、"Hidden"、"Compress"
4. **帧率 30fps**
5. **只用 AE 原生形状图层/矢量**，不要用位图（导出后位图会丢失或体积爆炸）
6. 不支持: 图层混合模式部分效果、AE 表达式、3D 图层
7. 导出后在 [lottiefiles.com](https://lottiefiles.com) 预览确认
8. 循环动画: 首尾帧完全一致确保无缝循环
9. 单次播放: 最后停在结束帧，不要自动回到第一帧
