> **交付目录**: `/public/assets/{category}/`
> **更新日期**: 2026-07-27

---

## 一、命名规范（必读）

```
{类别}_{标识}_{状态/变体}.{扩展名}

类别: char / scene / food / badge / ui / fx / card
标识: 角色名/物品名拼音（如 xiaoyuan / cake）
状态: idle / happy / sad / worry / bronze / silver / gold
扩展名: png / svg / json
```

**示例**:
- `char_xiaoyuan_idle.json` — 菌小园待机动效
- `scene_mid_high_sugar.png` — 中景高糖状态
- `badge_persist_7d_gold.png` — 一周之星金徽章

**禁止**:
- 中文文件名
- 空格、特殊字符、大小写混用
- 无意义编号（如 `img_001.png`）

## 附录 B：Lottie 制作要点

**工作流**:
1. AI/PS 中设计角色各部件（身体、四肢、五官、装饰），**分层命名**
2. 导入 AE，对每层做关键帧动画（位移/旋转/缩放/透明度）
3. Bodymovin 插件导出 `.json`，勾选 "Glyphs"、"Hidden"、"Compress"

**注意事项**:
- 帧率 30fps
- 只用 AE 原生形状图层/矢量，**不要用位图**（导出后位图会丢失或体积爆炸）
- 不支持的特性: 图层混合模式中的部分效果、AE 表达式、3D 图层
- 导出后在 [lottiefiles.com](https://lottiefiles.com) 预览确认效果
- 循环动画: 首尾帧完全一致，确保无缝循环
- 单次播放: 最后停在结束帧，不要自动回到第一帧
