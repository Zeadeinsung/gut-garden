# 肠道花园 Gut Garden — 科学传播作品交流材料

> **面向**：赛事组织方 / 评委的作品介绍与交流要点
> **主题**：科学传播的多元艺术表达（AI 驱动）
> **一句话定位**：把"肠道微生态"这座看不见的花园，做成孩子能看、能玩、能懂、能养成习惯的互动科普作品
> **一句话亮点**：三类赛道全占、同一个科学内核、AI 贯穿从"创作"到"交互"到"自修正"的全流程，且可复用

## 一、电梯演讲（30 秒版）

你的肠道里住着万亿个微小居民，它们组成了一座花园——这是我们的第一句话，也是整个作品的种子。

我们做的是一个 **"肠道花园"科普作品**：孩子可以拖拽食物进花园，看它变绿还是变脏；可以问常驻的 AI 导游「菌小园」十万个为什么；可以记录每天"便便天气报告"，让系统生成专属的饮食任务；坚持打卡，花园从种子一路长成大树。

它同时覆盖比赛的**三类赛道**：期刊级的科普视觉系统、可上手玩的数字交互装置、一部 90 秒 AI 生成的粘土动画科普片。而且整套东西不是"一次性作品"——**AI 生成内容、AI 讲解、AI 质检自修正**，是一个可以复用、会自我纠错的生产系统。

## 二、我们想传播的科学问题

**肠道微生态**——肠道里的万亿微生物如何影响健康？吃什么会"喂养"哪些居民？为什么医生总说要多吃膳食纤维？

它的难点是**看不见**。微生态藏在体内，抽象、专业、难以让孩子和家长产生直观认知。

我们的传播策略是把科学"翻译"成可看可玩的体验：

> 肠道 = 花园｜微生物 = 居民｜食物 = 养分｜便便 = 花园寄来的天气报告

科学内核（全部有据可依）：
- 膳食纤维是肠道"居民"的食物，食物多样性决定菌群多样性
- 纤维经发酵产生短链脂肪酸（SCFA）——滋养肠道屏障的"魔法养分"
- 饮食单一、熬夜、滥用抗生素会让花园"天气"变差，但每天都可以修复它

我们把这三条知识做成了**完整的传播闭环**：看 → 玩 → 懂 → 做 → 再验证。孩子不是"被灌输知识"，而是在互动里自己"发现"规律。

## 三、作品全貌：一个 IP，三类赛道全覆盖

### 3.1 经典期刊视觉类 —— 科普视觉系统

我们搭建了一套期刊级的视觉体系，把抽象机理变成可读的图：

| 视觉作品 | 内容 | 科学意义 |
|---------|------|---------|
| **五大知识模块卡片**（20+ 张） | 膳食纤维广场 / 发酵工坊 / 短链脂肪酸泉 / 肠道屏障城墙 / 生态平衡观测站 | 把微生态知识模块化，每张卡正面插画、背面可展开家长模式科学详述 |
| **布里斯托便便分型图表** | 7 种卡通化便便形态（兔子便便→水水） | 把临床分级可视化，孩子看得懂、家长用得上 |
| **SCFA 产生链路图** | 纤维 → 发酵 → 丁酸 → 滋养屏障 | 一张图讲清"纤维为什么重要"的底层机制 |
| **肠道屏障机理示意图** | 黏液层、肠上皮细胞、紧密连接 | 用"城墙 + 栅栏扣锁"的隐喻讲透"肠漏"概念 |
| **花园生态系统全景图** | 期刊封面风格的肠道花园大地图 | 一图看全整套生态隐喻 |

这些图不是插图，而是**"图文摘要"级的科学图解**——每张都能独立用于科普海报、教材配图、论文封面。

### 3.2 数字交互与体验类 —— 核心互动装置

这是我们作品的"心脏"：一个真正能玩的**互动式科普装置**。

**玩法一：食物投喂，花园实时变化**
- 拖拽食物进花园，看生态立刻反应：
  - 拖入**高糖高脂食物** → 坏菌膨胀、溪流油污、场景变暗
  - 只喂**干硬食物 + 缺水** → 土地龟裂、种子干瘪
  - 喂**纤维种子 + 水分** → 风车转动、泉水产出、花园恢复明亮
- 孩子在 5 秒内就"看见"了：吃什么，真的会改变你的微观世界。

**玩法二：便便"天气报告" → 动态饮食任务**
- 每天记录便便（7 种布里斯托形态，可选图标或拍照）
- 系统自动解析 → 生成**专属的今日饮食任务**（"今天多喝三杯水 + 吃一份蔬菜"）
- 这是**数据驱动的个性化科普**：每个孩子的花园状态都不同，建议也不同。

**玩法三：AI 导游「菌小园」常驻**
- 花园里随时可以问 AI："为什么放屁会臭？""酸奶对肠道有好处吗？"
- 回答严格限定在系统知识库内，**绝不编造**，医疗边界清晰。

**玩法四：成长与坚持体系**
- 花园成长 6 阶段（种子 → 幼苗 → 成长 → 丰收 → 大师 → 终极）
- 4 类徽章 × 铜银金三级，正向强化、断了不惩罚
- 打卡日历、里程碑、成长报告仪表盘（数据可视化，12 项指标）

这套装置把"科学传播"从"看完就忘"变成了"每天 3 分钟的行为养成"。

### 3.3 叙事与动态艺术类 —— 90 秒 AI 科普动画

我们用 AI 生产了一部 90 秒**粘土动画风格**的科普短片，六幕叙事：

1. **看不见的世界**：餐桌上的燕麦/水果，镜头沉入人体
2. **进入肠道花园**：穿过粉色隧道，花园豁然开朗，导游菌小园出场
3. **一粒纤维的旅程**：纤纤种子顺流而下 → 发酵工坊 → 泉水产出 → 流向屏障城墙
4. **花园也会变化**：饮食单一/熬夜/抗生素 → 花园变灰、乌云、局部雷雨；多样饮食 → 彩虹、花开、阳光回归
5. **互动网页演示**：真实录屏展示上面的交互装置
6. **结尾**：所有角色集结谢幕，镜头拉回餐桌，形成"圆满"

目前已产出 4 个核心知识片段视频（纤维 / 发酵 / 短链脂肪酸 / 肠道屏障），统一在"粘土 + 绒布 + 粉蓝绿童话色板"风格下。

## 四、AI 是如何贯穿整个创作过程的（重点）

这是本次交流最想展开的部分——**AI 不是其中一个功能，而是整个作品的"生产方式"**。

### 4.1 AI 造动画：把"讲科学"变成"讲故事"

我们搭建了一条 **AI 视频生产线**（基于阿里云百炼 ComfyUI + 通义万相 Wan）：

- **分镜即数据**：把 90 秒拆成 17 个分镜，每个分镜一条结构化 Prompt（场景、动作、时长、镜头运动），存在 JSON 里
- **统一风格**：全局"正向提示词前缀 + 负向提示词"，锁定粘土动画、绒布质感、粉蓝绿童话色板——**170 个 AI 镜头共用一套审美**
- **角色一致性**：5 个主角（菌小园/纤纤种子/发酵工匠/丁丁泉灵/屏屏守卫）先做角色设定图，再用 IP-Adapter 注入，**同一个角色全片不换脸**
- **批量无人值守**：一个脚本循环提交生成任务，断点续传，17 个镜头连续出片

**吹点**：传统团队做一部 90 秒粘土动画需要建模师、动画师、渲染农场、少说一个月；我们用一个 AI 生产线，把一个非动画专业团队，变成了"能出电影感成片"的动画工作室。

### 4.2 AI 当导游：科普对话「菌小园」

- 用**通义千问大模型**驱动，把整个"肠道花园知识库"注入模型上下文，回答**只依据知识库、绝不编造**（连 Bristol 便便分型、营养成分这类数字都不许乱说）
- 配了 7 条风格规则：花园隐喻开头、先给短结论、结尾给可行动建议、医疗边界清晰（不诊断、不恐吓、不舒服就去找医生）
- 流式打字输出，像真人在聊天；没网/模型超时自动降级到预设 FAQ，**体验永远不中断**

### 4.3 AI 看懂图：从"看图"到"懂图"

- **便便照片分析**：拍照上传 → AI 视觉理解（通义千问 VL）→ 识别布里斯托类型 → 生成动态饮食任务。孩子形态图 + 家长诊断图，双阅读层级
- 这套视觉理解能力还会用在**内容质检**上（见第五节）

### 4.4 AI 声音（规划中）

- 用通义 CosyVoice 给动画配儿童向旁白，Paraformer 做语音问答输入——让 3-6 岁还不会打字的低龄孩子也能和菌小园对话

## 五、可复用 + 自修正：我们的"AI 科普工厂"（加分项）

比赛说明里提到加分条件：**"可复用生成的 AI 应用"**、**"单次生成后能自动发现不足并修正，或在寻求人类建议后修正"**。这两条正是我们设计的核心。

### 5.1 为什么可复用：内容与流水线完全解耦

我们刻意把"科学内容"和"生成流水线"做成两张皮：

| 层 | 是什么 | 换主题时 |
|----|--------|---------|
| 知识库 | 数据文件（肠道知识、FAQ、便便分型、阶段规则） | 换内容即可 |
| 分镜脚本 | JSON 模板（17 个场景的 Prompt + 参数） | 换 Prompt 即可 |
| 风格系统 | 角色设定图 + IP-Adapter + 全局色板 | 一套资产走天下 |
| 生成工作流 | ComfyUI 工作流 + 批量脚本 | 不动 |

**这意味着**：同一套"AI 科普装置"，换一个科学主题（人体免疫、气候变化、蜜蜂生态、海洋污染……），**一周内可以再生产一套作品**——新的动画、新的知识库、新的交互页面框架。

再进一步，我们可以把它产品化成一个 **"输入科学主题 → 自动产出科普视频脚本 + 提示词 + 可交互页面"的 AI 应用**，让任何一个科普创作者都能用它"造科普"。

### 5.2 自我修正闭环：AI 自己审自己的片子

我们的生成不是"跑一次就完"，而是 **生成 → 质检 → 修正 → 人审** 的循环：

1. **生成**：AI 产出图像/视频片段
2. **自动质检**：用通义千问 VL 逐帧检查——文字有没有拼错？有没有畸变/多指/破相？角色有没有走样？风格有没有漂移？构图有没有截断？
3. **自动回炉**：发现问题后自动修正——调 seed、重写局部提示词、图生图局部重绘、图生视频续帧，直到通过质检
4. **人审沉淀**：人工最终审片，把"人的审美经验"写回提示词库和质检规则——**系统越用越懂你的风格**

**吹点**：它不是一个"一次性生成的 AI 工具"，而是一个**会自己挑毛病、越用越准的生成系统**——正好对应比赛加分的两个条件。

## 八、交流时可以聊的 5 个亮点（对话钩子）

1. **一个人 + AI = 一个团队**：从分镜、出图、出片、配音到交互页面，全流程 AI 化，一个人把过去一个工作室的活干完了
2. **三类赛道我们全占**：期刊视觉、数字交互、动态叙事，用的是**同一个 IP、同一个科学内核**——不是三件作品，是一套体系
3. **交互装置是真的能玩**：拖食物看花园变脏变绿、便便报告生成专属任务、问菌小园、攒徽章——孩子 30 秒上手，家长愿意每天陪 3 分钟
4. **AI 会自我修正**：生成完让 AI 自己审片、自己回炉，越用越懂你的风格——不是"一次性生成"，是"会进化的生产线"
5. **可复用**：内容与流水线解耦，换个科学主题一周再生产一套——这就是比赛要的"可复用生成的 AI 应用"

## 九、结语

我们想证明一件事：**科学传播的下一个时代，不是"把科学画出来"，而是"让每个人都能用 AI 把科学造出来"。**

肠道花园是这个理念的第一个完整实践——它用 AI 造了动画、造了交互、造了一个会自我修正的科普生产系统。它讲的是一个科学问题，但更想展示的，是一套可复用的方法：**让科学，能被看见，能被玩到，能被听懂，能被生产。**
