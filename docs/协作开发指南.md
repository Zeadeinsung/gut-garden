# 协作开发指南 — 肠道花园

> 写给零基础队友的 GitHub 协作手册。照着做就行，不用理解原理。

---

## 一、概念速查

| 名词 | 什么意思 |
|------|----------|
| **仓库（Repo）** | 项目的网盘，所有代码和素材都在这 |
| **Clone** | 把网盘上的项目下载到自己电脑 |
| **Commit** | 存个档，拍个快照。改了东西先存档才能上传 |
| **Push** | 把本地存档上传到网盘 |
| **Pull** | 把网盘上别人的更新下载到自己电脑 |
| **分支（Branch）** | 你自己的工作台，改烂了也不影响主版本 |
| **Pull Request（PR）** | 申请把你的修改合并到主版本，让队友看一眼确认 |
| **Merge** | 确认没问题，合并进去 |

## 二、第一次上手

### 2.1 安装 Git

- Windows：去 `https://git-scm.com/download/win` 下载安装，一路点"下一步"
- Mac：打开终端，输入 `git --version`，按提示安装

### 2.2 配置用户名（GitHub 才知道是谁改的）

打开**终端**（Windows 搜"PowerShell"，Mac 搜"终端"），输入：

```bash
git config --global user.name "你的GitHub用户名"
git config --global user.email "你的GitHub注册邮箱"
```

### 2.3 下载项目

```bash
git clone https://github.com/Zeadeinsung/gut-garden.git
cd gut-garden
```

成功后，你电脑上就多了一个 `gut-garden` 文件夹，里面就是项目。

## 三、日常工作流（每次改动这样做）

### 3.1 开工前：同步最新代码

```bash
git checkout master          # 切回主分支
git pull                     # 拉取队友的最新更新
```

### 3.2 创建自己的分支

起名规则：`功能/具体内容`

```bash
# 工程师
git checkout -b feature/打卡页面动画

# 美工
git checkout -b asset/菌小园idle动效
```

### 3.3 干活，改文件

正常用工具改代码/画图，保存到对应文件夹里。

### 3.4 存档（Commit）

```bash
git add .                    # 把所有修改加入待存清单
git commit -m "feat: 完成了打卡页面三个任务的确认动画"
```

> 引号里写清楚你干了什么。四个开头词二选一：
> - `feat:` — 新功能/新素材
> - `fix:` — 修 bug / 改问题
> - `asset:` — 纯美术素材（美工专用）

### 3.5 上传（Push）

```bash
git push origin 你的分支名
```

比如：

```bash
git push origin feature/打卡页面动画
```

## 四、提交审核（Pull Request）

### 4.1 创建 PR

推上去后，打开 `https://github.com/Zeadeinsung/gut-garden`，页面顶部会有黄色提示条，点 **Compare & pull request**。

如果没看到提示条：
1. 点顶部的 **Pull requests** 标签
2. 点绿色的 **New pull request**
3. `compare` 选你自己的分支，`base` 保持 `master`
4. 点 **Create pull request**

### 4.2 写清楚改了什么

标题：一句话说明

描述：
```
## 改了啥
- 打卡页面三个任务卡片加了确认后的星星动画

## 截图
（贴图，拖进来就行）

## 需要谁看
@队友GitHub名
```

### 4.3 队友 Review

- 队友点进 PR，能看到所有改动
- 没问题 → 点 **Merge pull request** → 合并完成
- 有问题 → 鼠标移到代码行号旁边，点蓝色 `+`，写评论
- 改完再 Push 一次，PR 会自动更新

## 五、常见情况处理

### 5.1 "你 push 失败了，说我落后了"

说明队友在你之前改了东西。这样处理：

```bash
git checkout master
git pull                            # 先把主分支更新
git checkout 你的分支名
git merge master                    # 把主分支的更新合进来
```

如果有冲突（Git 提示 CONFLICT），别慌，截图发给有经验的人帮你解。

### 5.2 "我想放弃所有改动重来"

```bash
git checkout .                      # 放弃所有未存档的修改
```

### 5.3 "我 commit 信息写错了"

```bash
git commit --amend -m "新信息"
```

### 5.4 "美工怎么提交 PNG/Lottie 文件"

和代码一样，放到 `web/public/assets/` 对应文件夹，然后 `git add` → `git commit` → `git push`。大文件（超过 50MB）先跟工程师说一声。

| 文件类型 | 路径 |
|----------|------|

| 场景图层 PNG | `web/public/assets/scenes/` |
| 食物道具 PNG | `web/public/assets/foods/` |
| 徽章 PNG | `web/public/assets/badges/` |
| UI 图标 SVG | `web/public/assets/ui/` |
| 特效 Lottie JSON | `web/public/assets/fx/` |
| 科普卡片 | `web/public/assets/cards/` |
| 音效 MP3 | `web/public/assets/sounds/` |

## 七、遇到问题怎么办

1. **看上面的表，用大白话描述问题**
2. **到 `https://github.com/Zeadeinsung/gut-garden/issues` 新建 Issue**
3. **截图或贴报错信息**，别只说"出错了"
