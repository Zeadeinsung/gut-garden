**优先级**: P0 | **预估**: 3h | **依赖**: A08/A09/A10 完成（三层基础稿）

**整体思路**：花园 3 层视差场景在高糖状态下**三层整体切换**，保证画面情绪统一（天空变暗、中景油污、前景出斑），不只换中景。

| 项目 | 内容 |
|------|------|
| **文件名** | `scene_garden_sky_high_sugar.png` / `scene_garden_mid_high_sugar.png` / `scene_garden_front_high_sugar.png` |
| **格式** | PNG-24，透明背景 |
| **画布** | 1920×1080 px |
| **放在哪个文件夹** | `web/public/assets/scenes/` |

**怎么画**：分别基于 A08/A09/A10 的三层基础稿做以下颜色调整：
- **Sky 层**：整体色调偏暗黄，云层饱和度降低、显得低沉
- **Mid 层**：溪流变油污浑浊色（蓝色→灰棕色）、植被出现暗斑（局部加深）、坏菌膨胀（菌居民之家附近紫色/暗色斑点）、整体色调偏暗黄（色相偏移 -10°，饱和度 +5%）
- **Front 层**：前景植被出暗斑、栅栏偏灰偏暗、野花褪色

> 提示：在 Photoshop 里分别打开 A08/A09/A10 → 各新建调整图层（色相/饱和度）→ 导出 3 张
