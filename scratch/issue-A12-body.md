**优先级**: P0 | **预估**: 2.5h | **依赖**: A08/A09/A10 完成（三层基础稿）

**整体思路**：花园 3 层视差场景在干旱状态下**三层整体切换**，保证画面情绪统一（天空灰、中景干裂、前景干枯），不只换中景。

| 项目 | 内容 |
|------|------|
| **文件名** | `scene_garden_sky_dry.png` / `scene_garden_mid_dry.png` / `scene_garden_front_dry.png` |
| **格式** | PNG-24，透明背景 |
| **画布** | 1920×1080 px |
| **放在哪个文件夹** | `web/public/assets/scenes/` |

**怎么画**：分别基于 A08/A09/A10 的三层基础稿做以下调整：
- **Sky 层**：整体饱和度降低 40%，云层稀疏带灰、太阳光晕变淡
- **Mid 层**：溪流干涸露河床（局部改为土黄色/龟裂纹理）、植被偏灰偏黄、土地龟裂（溪流区域加裂纹笔刷）
- **Front 层**：前景草丛干枯偏黄、花朵凋谢、石头/栅栏蒙尘发白

> 提示：在 Photoshop 里分别打开 A08/A09/A10 → 各新建调整图层（色相/饱和度/裂纹笔刷）→ 导出 3 张
